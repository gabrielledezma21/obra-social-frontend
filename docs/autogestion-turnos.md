# Autogestión de turnos

Desde la pantalla de acceso se puede ingresar a `Gestionar turno con código` sin iniciar sesión.

La pantalla solicita el código de reserva y la clave de gestión entregados al crear el turno. Con esas credenciales permite:

- consultar los datos del turno;
- buscar horarios alternativos;
- reagendar;
- cancelar.

Al reservar un turno desde el portal del afiliado se muestran el código y la clave una sola vez. La clave no se guarda en el navegador.

Las validaciones de seguridad y la regla de anticipación mínima se aplican en el backend; el frontend solo presenta la experiencia de usuario.
